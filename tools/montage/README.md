## 0. Как начать новый чат (самое важное)

1. Откройте новый чат в проекте «ИИ команда». Документы проекта и память Claude видит в любом чате этого проекта.
2. Приложите этот PDF или напишите: «Прочитай документ проекта `claude/база-видеомонтажа.md`».
3. Приложите видео и напишите задачу. Пример стартового сообщения:

> Прочитай документ проекта «база-видеомонтажа». Подключи репозиторий costa0001/chernoviki-stori с правом записи, запусти `tools/montage/setup.sh` и смонтируй урок из приложенного видео по разделу 6. Вопросов не задавай, доведи до готового файла.

4. Первое, что делает Claude в новом чате:
   - подключает репозиторий GitHub `costa0001/chernoviki-stori` (инструмент add_repo, доступ push) и клонирует его в `/home/claude/chernoviki-stori`;
   - запускает `bash /home/claude/chernoviki-stori/tools/montage/setup.sh` (ставит пакеты, качает модель распознавания, рисует рамку спикера);
   - дальше работает по нужному разделу этого документа.

Почему новый чат дешевле: каждый ответ Claude перечитывает всю историю чата. Длинная история с расшифровками и картинками кадров стоит дорого. Новый чат с этим документом начинается почти с нуля, а опыт сохраняется.

## 2. Рабочая среда Claude

- Мощность в последних сессиях: **2 ядра процессора, 8 ГБ памяти**. Раньше бывало больше. Скорость всех оценок ниже дана для 2 ядер.
- Сеть ограничена: доступны GitHub, pip, npm. Hugging Face и большинство сайтов закрыты. Онлайн-распознавание речи недоступно, поэтому распознавание идёт локально.

- Модели распознавания (Whisper в формате ONNX из проекта sherpa-onnx) качаются с GitHub Releases:
  - small: `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-whisper-small.tar.bz2` → `/home/claude/asr/sherpa-onnx-whisper-small/` (файлы `small-encoder.int8.onnx`, `small-decoder.int8.onnx`, `small-tokens.txt`);

- Готовый файл отдаётся через **SendUserFile** (карточка файла в чате) и дублируется в GitHub.

## 3. Общий конвейер (любое видео)

1. **Копия и осмотр.** `ffprobe` (длительность, размер, частота кадров), 4–6 кадров в один контактный лист: где лицо, где слайд, есть ли зеркальность, чёрные кадры, мусор интерфейса.
2. **Расшифровка фоном** сразу после копирования (раздел 4). Пока она идёт, настраивается раскладка кадра.
3. **Чтение расшифровки один раз**, компактно: «время начала + текст». Выбор, что вырезать.
4. **Спорные места** (3–10 штук) проверяются моделью medium одной пачкой.
5. **Монтажный лист** (какие интервалы оставить) и **рендер одним проходом**, видео и звук параллельно.
6. **Проверка**: 4 кадра из готового файла, повторная расшифровка 1–2 главных склеек.
7. **Отдача**: файл в чат, копия в GitHub, короткий отчёт.

## 4. Расшифровка речи

**Скрипты:** `tools/montage/asr.py` (ядро: мел-спектр и декодер Whisper small) и `tools/montage/fast_asr.py` (один проход по фразам).

Запуск в рабочей папке, фоном:

```
cd /home/claude/lesN && python3 /home/claude/chernoviki-stori/tools/montage/fast_asr.py src.mp4 ph.jsonl > asr.log 2>&1
```

Что делает:
1. Вынимает звук `a16.wav` (моно, 16 кГц).
2. Ищет паузы: `silencedetect=noise=-35dB:d=0.35`, лог сохраняет в `sil.txt` (он же нужен для монтажного листа).
3. Склеивает фразы с промежутком меньше 0,45 с в куски до 9 с.
4. Распознаёт каждый кусок моделью **small int8**, язык русский, жадное декодирование, защита от зацикливания.
5. **Укороченное окно энкодера:** мел-спектр длиной «звук + 400 кадров» вместо полных 30 с. Это в 3,5 раза быстрее при том же качестве.
6. Пишет `ph.jsonl`: строки `{"s": начало, "e": конец, "t": "текст"}`. В конце лога слово `ASRDONE`.

**Скорость на 2 ядрах:** 20–24 минуты речи распознаются за 8–10 минут.

**Спорные места** проверяются моделью medium (`tools/montage/asr_medium.py`, нужно скачать medium):

```
echo '[[279.0,285.0],[1285.5,1292.5]]' > c.json
python3 asr_medium.py a16.wav c.json co.json
```

Small часто ошибается так: повторяет одно слово много раз («в вечером, в вечером…»), пишет «[музыка]», «Смешно», «(смех)» на месте шума или смешка, путает имена и цифры. Medium в этих местах обычно показывает, что сказано на самом деле.

**Если английская речь** (чужие референсы): в `asr.py` заменить `codes.index('ru')` на `codes.index('en')`.

**Готовая расшифровка от Константина** (.vtt, .srt из Zoom, CapCut, YouTube) берётся за основу, и распознавание можно пропустить.

## 5. Что вырезается и как найти точку разреза

Вырезается:
- чёрный кадр в начале (обычно первые 2–3 с);
- паузы длиннее ~0,35 с (между фразами остаётся естественный воздух);
- шумы, отмеченные в расшифровке как «[музыка]», «СПОКОЙНАЯ МУЗЫКА», «*звук…*»;
- смешки и короткие возгласы: «Смешно.», «(смех)», «Ай.», «Фаса!»;
- междометия и обрывки: «А…», «Ах», «Ну, скажем так», «Е.»;
- оговорки: «в течение 20… 24 часов» → остаётся «24 часов»; «перед сном, зелёных… когда» → «перед сном. Когда»;
- дубли: если фраза сказана несколько раз, остаётся последний полный вариант;
- команды монтажёру в кадре: «это вырезаем», «приступаем к монтажу»;
- в эфирах: приветствия зрителей, обращения к людям из чата, технические сбои, непроверенные цифры.

Что **не** вырезается: живые повторы для усиления («Мы её заменяем. Мы её…»), если разрез был бы заметнее повтора.

**Точка разреза внутри фразы** ищется по профилю громкости с шагом 50 мс:

```
python3 -c "
import numpy as np
a=np.fromfile('a16.wav',np.int16,offset=44).astype(float)/32768
for t in np.arange(283.0,285.2,0.05):
  x=a[int(t*16000):int((t+0.05)*16000)]; print(f'{t:.2f}:{20*np.log10(np.sqrt((x**2).mean())+1e-9):.0f}', end=' ')"
```

Провал до −40…−60 дБ между словами и есть место разреза. Затем кусок до разреза распознаётся medium: слышно ли последнее нужное слово целиком.

## 6. Видеоуроки клуба (запись экрана)

### Исходник
Запись Zoom, **1920×1030, 25 кадров/с**. В браузере открыт PDF-презентация (вкладки, адресная строка, панель PDF сверху). Камера Константина в правом верхнем углу (x 1600–1920, y 0–180), снизу у камеры плашка Zoom «Konstantin Bravo».

### Результат
**1920×1080, 25 кадров/с.** Слайд (белая страница PDF) растянут на весь кадр. Вкладки, адресная строка, панель PDF и серые поля убраны. Окно камеры **344×258** в точке **(1548, 28)**, прямо на слайде справа сверху: скругление 22 px, синяя рамка 4 px (RGB 30, 95, 220), мягкая тень, плашка «Константин Браво» (Inter SemiBold 22, тёмно-синяя, 225/255 непрозрачности).

### Раскладка (параметры)
- Страница PDF в исходнике: `crop=1536:862:181:158` (ширина:высота:x:y), затем `scale=1920:1080`.
- Верхние 34 px страницы закрашиваются цветом страницы `#FAFBFE`: там всплывают подсказки браузера («Следующая страница»).
- Камера: `crop=208:156:1652:0` (без плашки Zoom), `scale=344:258:flags=lanczos`.
- Рамка, тень, скругление и подпись собраны **в одну картинку** `top.png` (скрипт `make_top.py`), накладывается в точку (1508, 0).
- **Проверка на новом исходнике:** если окно браузера сдвинуто, края страницы ищутся по пикселям (переход серого 225 к белому 250 по строке y=600 и по столбцу x=1000). На всех четырёх уроках ноября края совпали: x 181–1717, y 158–1020.

### Команды
```
mkdir -p /home/claude/lesN && cd /home/claude/lesN && cp "/mnt/user-data/uploads/<файл>.mp4" src.mp4
nohup python3 /home/claude/chernoviki-stori/tools/montage/fast_asr.py src.mp4 ph.jsonl > asr.log 2>&1 &
# … дождаться ASRDONE, прочитать ph.jsonl, выбрать что выкинуть …
python3 /home/claude/chernoviki-stori/tools/montage/lesson.py src.mp4 "Урок_Тема.mp4" --drop 62.9,197.4 --cut 1333.90-1335.05
```

`lesson.py`:
1. Строит монтажный лист из `sil.txt`: речь с запасом −0,08 с до и +0,16 с после, минус `--drop` (начала фраз из `ph.jsonl`), минус `--cut` (интервалы), минус первые `--head` секунд (по умолчанию 3).
2. Округляет все границы до кадра (1/25 с).
3. Видео: `select='between(t,a,b)+…'`, `setpts=N/25/TB`, раскладка, `libx264 -preset veryfast -crf 21 -tune stillimage`.
4. Звук параллельно: тот же `aselect`, `asetpts=N/SR/TB`, `loudnorm=I=-16:TP=-1.5:LRA=11`, AAC 160 кбит/с.
5. Склейка без перекодирования (`-c copy -movflags +faststart`), 4 контрольных кадра `q*.jpg`.
6. `--dry` только считает длительность.

## 7. Рилсы из записи с фронтальной камеры

### Подготовка
- iPhone пишет вертикальное видео как 1920×1080 с поворотом 90°, ffmpeg разворачивает сам.
- **Зеркальность:** фронтальная камера пишет зеркально, надписи на полках («БИБЛИЯ», «Longines») читаются наоборот. Видео разворачивается `hflip` **до** наложения текста. **Исключение для эфиров:** блокнот с формулой читается правильно, эти куски не зеркалятся. После монтажа проверяется увеличенный кадр с книгами.

### Нарезка (`tools/montage/reel_cut.py`, пример с монтажным листом внутри)
- Список кусков `(начало, конец, текст, группа)`; берётся последний чистый дубль каждой фразы.
- Запас: −0,07 с до, +0,17 с после; длительность куска округляется до кадра (1/30 с).
- **Динамика:** группы чередуют общий план и приближение 1,13× (обрезка с упором в лицо, 30 % от верха). Склейки не видны, ролик живее.
- Затухание звука 20–30 мс на стыках против щелчков; громкость `loudnorm=I=-15:TP=-1.5:LRA=9`.

### Субтитры (`tools/montage/reel_subs.py`)
- Шрифт **Inter ExtraBold 78 px**, белый, обводка 3 px тёмно-синяя (10, 30, 80).
- Плашка тёмно-синяя 215/255, скругление 28, синяя рамка 4 px (70, 130, 230), мягкая тень.
- Ключевые слова голубым (120, 200, 255); список слов задаётся в скрипте (`KEY`).
- Центр по вертикали **y = 1455** из 1920: чуть выше рук, крупно для аудитории 40+. Ширина строки до 900 px.
- 1–2 строки, до 30 знаков и до 5 слов на экран; время делится пропорционально числу букв; появление «поп» 0,86 → 1 за 0,14 с.
- Текст виден с первого кадра; если промежуток между субтитрами меньше 0,6 с, предыдущий держится до следующего.
- Хук сверху (y ≈ 120, 62 px) держится весь ролик; кодовое слово заглавными в «ёлочках».

### Нарезка прямого эфира
Скрипты `render.py`, `verify.py` для эфиров лежат в документе проекта `claude/скрипты-монтажа.md`. Особенность: в .mov эфира время расшифровки и время нарезки расходятся на **+0,526 с**; на новом исходнике сдвиг проверяется кросс-корреляцией одного куска. Смысловые истории 30 с – 3 мин, хук сверху 10–15 слов, который цепляет за боль и вызывает вопрос.

## 8. Серия коротких роликов по 8 секунд (кодовое слово)

**Скрипт:** `tools/montage/short8.py spec.json out.mp4` (пример: серия ЦЕЛИ, 15 роликов, октябрь 2026).

Спецификация ролика (JSON): `layout` (HIGH / LOW / BAND), `src`, `pieces [[начало, длительность], …]`, `z` (приближение), `fx`, `fy` (центр лица в долях кадра), `pl0`, `pl1` (зона плашек), `cta_y`, `flip`, `audio keep|mute`, `title [2 строки]`, `plates [6 строк]`, `yt` (версия для YouTube).

Раскладки:
- **HIGH:** лицо вверху, плашки ниже от `pl0` до 1626, призыв на y 1752.
- **LOW:** лицо внизу, плашки 318–838, призыв на 975 (или `cta_y`).
- **BAND:** горизонтальное видео полосой 1080×608 на y 300 поверх размытого, затемнённого и подкрашенного синим фона (`boxblur=40:3, eq=brightness=-0.20:saturation=0.75`, синий слой 0x0a1e50 45 %).

Оформление: заголовок Serif Condensed Bold 74 (автоуменьшение, если шире 1060 px), синий с белой обводкой 7 px; шесть плашек появляются по одной через 0,5 с, выезжают слева и справа; размер шрифта плашек подбирается 46 → 34, чтобы влезли; через 0,55 с после последней плашки пульсирует призыв «Напишите слово ЦЕЛИ…» (для YouTube: «Переходите по ссылке ПОД ЭТИМ ВИДЕО»). Медленный общий наезд `zoompan 1+0.0004*on`.

**Правила серии (ошибка 21.10.2026):**
- Нельзя добирать количество однотипными кадрами (11 роликов из одного кресла с жестом включения камеры).
- «Неиспользованные фрагменты» значит новые моменты любых видео, частичное пересечение допустимо, тот же кусок нельзя.
- Подряд не ставить одну локацию (два Монако подряд неинтересно). Порядок серии составляется до сборки.
- Видеохук с первого кадра: движение, эмоция, улыбка, узнаваемое место.
- Около 7 триггеров для 40+ в каждом ролике (возраст, время, деньги, пенсия, выгорание, дети, ровесники, работа).
- Перед отправкой контактный лист первых кадров всей серии.

## 9. Версия для YouTube

- Призыв «напишите в комментариях слово…» вырезается.
- Для рилсов: последний кадр замирает на 3,5 с, на нём белая табличка с синей рамкой «Переходите по ссылке ПОД ЭТИМ ВИДЕО…» и подпрыгивающая синяя стрелка вниз.
- Для серии 8 с: в спецификации `"yt": true`, табличка призыва меняется автоматически.
- Название Shorts начинается с «🎁», до 100 знаков, например «🎁 Выгорели и потеряли направление? Бесплатный практикум по ссылке 👇».

- Ссылки в описании Shorts бывают некликабельными; при необходимости «Связанное видео» добавляется вручную в YouTube Studio.

## 10. Тексты подписей

Правила голоса Константина:
- только русский язык, обращение на «вы»;
- без конструкции «не X, а Y» и без отрицающих обращений («Вы не ленивы»), минимум отрицаний, без длинных тире;
- только подтверждённые цифры: 340 000+ подписчиков; 300 000 за первый год без рекламы; 100M+ охвата за 2025 год; 100+ учеников; начал в 52 года в новой стране; инженер; 28 лет в бизнесе; «раньше 10 часов, сейчас 1 час, остальное ИИ».

Подпись Instagram (~1900 знаков, кодовое слово заглавными 3 раза):
1. Призыв с кодовым словом.
2. Хук (вопрос) и 2 абзаца боли.
3. Средний призыв (+ «Даже если пока сомневаетесь, напишите слово: решение вы примете сами, когда посмотрите приглашение.»).
4. Описание продукта (для ЦЕЛИ: бесплатный практикум воплощения целей, старт 2 ноября, 5 дней).
5. «За пять дней практикума:» и 4 пункта.
6. Упражнение, своё для каждого ролика.
7. Подтверждённый факт о Константине.
8. P.S. (для кого продукт).
9. «Сохраните ролик и отправьте тому, кому это сейчас нужно.»
10. Финальный призыв. 11. Хэштеги `#цели #практикум #жизньпосле40 #мечты #КонстантинБраво`.

Описание YouTube (~850–900 знаков): строка с эмодзи и ссылка; хук; короткое тело; описание продукта; «👉 Забрать бесплатное место: ссылка»; факт; для кого; «✅ Регистрация здесь: ссылка»; подсказка про описание; хэштеги.

## 11. Публикация через Metricool

- Видео заливается в GitHub, в Metricool передаётся прямая ссылка raw.githubusercontent.com (Metricool сам копирует файл к себе).
- Время по Киеву. До 25 октября смещение **+03:00**, с 25 октября по конец марта **+02:00**.
- Instagram (createScheduledPost):

```json
{"autoPublish": true, "descendants": [], "draft": false, "firstCommentText": "", "hasNotReadNotes": false,
 "media": ["https://raw.githubusercontent.com/costa0001/chernoviki-stori/main/reels/celi/06_gg_tolpa.mp4"],
 "mediaAltText": [], "providers": [{"network": "instagram"}],
 "publicationDate": {"dateTime": "2026-10-22T16:20:00", "timezone": "Europe/Kyiv"},
 "shortener": false, "smartLinkData": {"ids": []}, "text": "<подпись>",
 "instagramData": {"type": "REEL", "showReelOnFeed": true}}
```
плюс параметры `blogId 5124907` и `date "2026-10-22T16:20:00+03:00"`.

- YouTube: `providers [{"network":"youtube"}]` и
`"youtubeData": {"title": "🎁 …", "type": "short", "privacy": "public", "madeForKids": false, "category": "EDUCATION", "tags": [...]}`.
- Правка поста: updateScheduledPost с id и uuid; после правки id меняется, uuid остаётся; передаётся полное содержимое поста.
- getScheduledPosts возвращает много данных: запрашивать по 1–2 дня и разбирать сохранённый файл скриптом.
- Типичная сетка дня (Киев), куда вставлялись новые рилсы между существующими: 09:00, 09:40, **10:30**, 11:00, 11:15, **12:15**, 13:00, 13:30, 14:10, 14:30, **16:20**, 17:15, **17:50**, 18:40, **19:30**, 20:15, **21:10**.

## 12. Ошибки, которые уже были (не повторять)

1. **Зависший рендер урока (03.11.2026, потеряно больше часа).** Три картинки с `-loop 1` (тень, маска, рамка) в одном фильтре: ffmpeg копил кадры в памяти до 1,7 ГБ и работал в разы медленнее. Решение: все украшения в одну картинку `top.png` без `-loop`; видео и звук рендерить отдельно и параллельно; **скорость проверять через `-progress` в первую минуту** (норма 1,8–3x).
2. **Звук уплывает от видео.** Границы кусков не по сетке кадров: при 370 кусках ошибка копится до секунд. Решение: округлять до 1/25 с (уроки) или 1/30 с (рилсы).
3. **Сдвиг 0,526 с в .mov эфира** между временем расшифровки и нарезки. Решение в `render.py` эфира: `-ss` до `-i` с запасом 4 с, затем `trim/atrim` и поправка.
4. **`afade` при `-ss` после `-i`** обнуляет звук. Обрезать только через `trim/atrim`.
5. **Нехватка памяти** на одном большом фильтре concat: кодировать половины отдельно и склеивать демуксером concat.
6. **Одинаковые ролики в серии** (раздел 8).
7. **NBSP в «340 000»** разрывал строку: в Python `str.split()` режет по неразрывному пробелу, нужен `split(" ")`.
8. **Ожидание процессов.** `pgrep -f` в цикле находит сам себя; `pkill -f` убивает свою оболочку; долгий `sleep` запрещён. Решение: фоновая команда с циклом `until … ; do sleep 10; done` и ожидание уведомления.
9. **Расход токенов.** Не выводить расшифровку в чат целиком, не писать скрипты заново, проверку склеек делать одну в конце, не перепроверять medium всё подряд (только 3–10 мест).
10. **Правка смонтированного урока:** время сверять по самому видео, звук, вынутый отдельно, может отличаться на доли секунды у стыков.

## 14. Аватар и чужие форматы (для справки)

- **«Цифровой аватар»** (перерисовка внешности, одежды и фона с сохранением речи): в среде Claude таких нейросетей нет. Нужен сервис правки видео по описанию, например Runway Aleph 2 или Luma Modify Video. Константин сам регистрируется и оплачивает тариф; Claude режет исходник на куски по 5–10 с с одинаковым описанием образа, прогоняет их через сервис в браузере Chrome и собирает ролик с окном «до» в углу, субтитрами и призывом.
- **Референсы из Instagram**: скачать видео по ссылке Instagram из среды Claude нельзя (сайт закрыт); видео присылается файлом.
